# АвтоПрогноз РФ — учебное демо

Только вымышленные цены, аналоги и сценарии. Не является сервисом оценки или финансовой рекомендацией. Реальные площадки и базы не подключены.

Это отдельная статическая сборка для некоммерческой демонстрации. Пользовательские данные и фотографии не отправляются на сервер; внешние API, аналитика и платежи отсутствуют. Визуальная и мобильная приемка еще предстоят. Ограничения бесплатного GitHub Pages применяются.

Версия и хеши: release.json.
