# АвтоПрогноз РФ

Веб-интерфейс для просмотра цен на автомобили, истории стоимости и прогнозных сценариев. Репозиторий содержит публичную статическую сборку проекта.

## Сайт

- [Основная площадка — GitHub Pages](https://saimonkingsley.github.io/autoprognoz-demo/)
- [Резервная площадка — Render](https://autoprognoz-demo-mirror.onrender.com/)

## Возможности

- Выбор автомобиля и его параметров.
- Просмотр истории стоимости на графике и в таблице.
- Отображение оценки на выбранную дату.
- Выбор горизонта прогноза и просмотр сценариев.
- Адаптивный интерфейс для компьютеров и телефонов.
- Проверка целостности файлов опубликованной версии.

## Статус проекта

Опубликована демонстрационная версия интерфейса. Текущие цены, история и прогнозы основаны на синтетических данных и не отражают состояние автомобильного рынка. Использовать их для оценки автомобиля или принятия решения о покупке и продаже нельзя.

Подключение реальных данных и проверка прогнозной модели — следующий этап разработки. Работа сайта на телефоне подтверждена пользователем; автоматические проверки опубликованной версии включают целостность файлов и основные сценарии интерфейса.

## Архитектура

Сайт работает в браузере и размещается как набор статических файлов. Для текущей версии не требуются сервер приложения и база данных. Внешние источники рыночных данных, платежи и аналитические системы не подключены. Пользовательские данные и фотографии на сервер не отправляются.

| Файл | Назначение |
| --- | --- |
| `index.html` | Структура страницы |
| `styles.css` | Оформление и адаптивная вёрстка |
| `app.mjs` | Логика интерфейса |
| `domain.mjs` | Предметная логика |
| `snapshot.mjs` | Встроенный набор демонстрационных данных |
| `release.json` | Идентификатор версии, размеры и SHA-256 файлов |
| `tools/check_demo.py` | Проверка состава и целостности сборки |

## Локальный запуск

Требуется Python 3. Из корня репозитория выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/` в браузере.

## Проверка сборки

```bash
python tools/check_demo.py
```

Для проверки синтаксиса JavaScript требуется Node.js:

```bash
node --check app.mjs
node --check domain.mjs
node --check snapshot.mjs
```

Проверки целостности также выполняются в GitHub Actions. Сборка для Render находится в ветке `mirror/render-demo-f15dd357e2e5`; публикуемый каталог — `public/`. Автоматическое развёртывание Render отключено.
