# Учебное статическое зеркало

Только вымышленные данные. Не использовать для покупки или продажи.

Публикуется только public/. Проверка: python3 -E check_demo.py public.
Конфигурация Render — static site, без API, БД, дисков и cron.
До создания ресурса проверить доступные квоты, тариф и отсутствие платного перерасхода.
Этот пакет не подтверждает создание сервиса или нулевую стоимость аккаунта.
Автопубликация выключена. Для следующего релиза использовать новый полный пакет.
